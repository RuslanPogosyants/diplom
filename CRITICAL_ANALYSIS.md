## 🖱️ UX/UI ПРОБЛЕМЫ

### Критичные
1. **Пустые вопросы на странице результатов**
   - `{{ question.question }}` отображает пустой блок
   - Проблема: либо данные не генерируются, либо структура JSON неверная
   - Нужно проверить `src/generate_questions.py` и формат вывода

2. **Нет обратной связи при ошибках**
   - `alert()` для всех ошибок - устаревший подход
   - Использовать Bootstrap toasts или модальные окна

3. **Отсутствие валидации форм**
   - Нет проверки размера файла перед загрузкой (client-side)
   - Нет проверки формата файла
   - Можно загрузить что угодно

### Высокий приоритет
4. **Отсутствие поиска/фильтрации** (`index.html`)
   - При 100+ видео найти нужное невозможно
   - Добавить поле поиска по названию/дате

5. **Нет сортировки таблицы**
   - Невозможно отсортировать по дате/длительности/статусу
   - Добавить сортируемые заголовки столбцов

6. **Отсутствие пагинации**
   - Все видео загружаются сразу
   - При >50 видео страница будет тормозить

7. **Нет индикатора прогресса загрузки**
   - `uploadFile()` не показывает прогресс XMLHttpRequest
   - Пользователь не видит прогресс 500MB файла

8. **Невозможно удалить результаты**
   - Старые обработки накапливаются
   - Нет кнопки удаления в таблице

### Средний приоритет
9. **Breadcrumb не работает**
   - `<li class="breadcrumb-item active">` - не кликабельный

10. **Нет preview для видео**
    - Сложно вспомнить какое видео без preview
    - Добавить thumbnail или первый кадр

11. **Детали раскрываются долго**
    - `<details>` в сегментах/вопросах - нет анимации
    - Добавить smooth transition

12. **Tabs не запоминаются**
    - При перезагрузке страницы возвращается на первый таб
    - Использовать URL hash или localStorage

## ⚙️ ФУНКЦИОНАЛЬНЫЕ ПРОБЛЕМЫ

### Критичные
1. **Вопросы генерируются пустыми**
   - Структура данных: нужен `question.question`, но возможно генерируется только `answer`
   - Проверить `src/generate_questions.py`

2. **Race condition при отмене**
   - `cancelProcessingBtn` не гарантирует остановку subprocess
   - Процесс может продолжить работу после "отмены"

3. **Нет recovery при обрыве сети**
   - Если сеть оборвется, прогресс теряется
   - Нужен механизм восстановления по checkpoint

### Высокий приоритет
4. **Session ID extraction может не работать**
   - `web_app.py:464`: regex `video_[\d_]+` может не совпадать
   - Если формат изменится, кнопка "Посмотреть результаты" не появится

5. **Поллинг каждые 1000мс избыточен**
   - При долгой обработке (1+ час) это 3600+ запросов
   - Увеличить интервал до 2000-3000мс

6. **Логи растут безгранично**
   - `output_lines` в памяти может достичь GB при долгой обработке
   - Ограничить последними 1000 строками

7. **Нет timeout для всего процесса**
   - Обработка может зависнуть навсегда
   - Добавить общий timeout (например, 6 часов)

### Средний приоритет
8. **Поиск статей может быть нерелевантным**
   - Даже с GigaChat запросы могут быть слишком общими
   - Нужна валидация релевантности результатов

9. **Нет деактивации кнопок**
   - "Начать обработку" можно нажать дважды
   - Disable кнопку после клика

10. **Uploadчерез drag&drop не показывает имя файла**
    - После drop непонятно какой файл выбран
    - Показать имя файла

## 🚀 ПРОИЗВОДИТЕЛЬНОСТЬ

### Высокий приоритет
1. **Все сессии загружаются сразу** (`web_app.py:39`)
   - `get_all_sessions()` читает все checkpoint.json
   - При 1000+ видео будет тормозить
   - Добавить lazy loading / pagination

2. **Чтение JSON при каждом запросе**
   - `load_session_data()` читает 8 JSON файлов
   - Нет кэширования
   - Добавить LRU cache

3. **Subprocess stdout читается построчно**
   - `web_app.py:420`: может тормозить при большом выводе
   - Использовать bufsize=8192

### Средний приоритет
4. **tqdm в subprocess**
   - Даже с `disable=True` создает overhead
   - Полностью убрать tqdm из subprocess кода

5. **Bootstrap Icons загружаются с CDN**
   - Каждая иконка - отдельный HTTP запрос
   - Перейти на icon font или SVG спрайты

## 🔒 БЕЗОПАСНОСТЬ

### Критичные
1. **Path traversal в file upload**
   - Нужна валидация пути файла
   - Проверить что файл сохраняется в безопасное место

2. **Нет CSRF защиты**
   - POST запросы не защищены
   - Добавить CSRF tokens

### Высокий приоритет
3. **Размер файла только на сервере**
   - Client может загрузить 10GB
   - Проверять на клиенте ДО загрузки

4. **Subprocess injection**
   - Параметры передаются в CLI без эскейпинга
   - Использовать `shlex.quote()`
